ANUGYA SATYAPAK · QUICK CHECK

Extension privacy notice

Last updated: October 10, 2026

The Anugya Satyapak Quick Check extension processes contract text locally in the Chrome popup. It does not send the text, page contents, or browsing history to Anugya Satyapak or another review service.

Information the extension handles

The extension handles text you select on a webpage, text you type or paste into its popup, and—only after you choose Read visible page—readable text shown on the current page. When you open the extension popup, it attempts to capture the text you have selected. The extension does not collect or store the page URL, browsing history, account details, or passwords.

How the text is used

The text stays temporarily in the open extension popup while the local English pattern scan creates a short report. The extension does not transmit the text to a server, use an AI provider, or save it to extension storage. Closing the popup discards the draft and report.

Copying text to the website

If you choose Copy text, the extension writes the text to your device’s clipboard so you can paste it yourself into the Anugya Satyapak website. Opening the website does not transfer text automatically. The extension does not control what happens to text after you paste it into the separate website.

Sharing, analytics, and remote code

The extension does not share the text with Anugya Satyapak or third parties. It has no analytics, advertising, tracking, remote scripts, or review API connection.

Permissions

  • activeTab: lets the extension access the current tab after you open its popup.
  • scripting: reads the selected text when the popup opens and reads visible page text only when you choose that action.
  • clipboardWrite: writes text to the clipboard only when you choose Copy text.

Contact

For questions or privacy requests, use the project’s GitHub support page. Do not include contract text or personal information in a public issue.
